# Security track

The security problem ProofGraph addresses is stale or unverifiable capability claims being treated as current trust—not transaction logging.

ProofGraph reduces that risk through specific-work evidence, verifier metadata, immutable creator provenance, Arkiv expiry, public challenge linkage, and independently attributable successor proofs. Active discovery applies the expiry floor in Arkiv rather than trusting a UI timestamp.

ProofGraph does not establish that a verifier is honest, make wallets unique identities, eliminate Sybil behavior, guarantee external artifact availability forever, or detect every compromised wallet. Consumers still need a verifier trust policy.
